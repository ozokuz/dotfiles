# Inactive migration reference

These are the old Arch/CachyOS files, not inputs to the new store. Do not run these
scripts as part of the rebuild. New package selections live in `catalog/`,
`bundles/`, and `hosts/` and were written independently.

The original `../dotfiles` checkout retains its original paths. Its live shell
symlinks are unchanged. Evaluate configuration here individually before reusing
it; do not deploy the whole tree.
